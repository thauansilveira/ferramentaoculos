# 🚀 Como Publicar no GitHub Pages

## ✅ Passo 1: Ativar GitHub Pages

1. Acesse: https://github.com/thauansilveira/ferramentaoculos
2. Clique em **Settings** (Configurações)
3. No menu lateral, clique em **Pages**
4. Em **Source**, selecione:
   - Branch: **main**
   - Folder: **/ (root)**
5. Clique em **Save**

## ✅ Passo 2: Acessar seu site

Após alguns minutos, seu site estará disponível em:
```
https://thauansilveira.github.io/ferramentaoculos/
```

## ✅ Passo 3: Testar a Câmera

- O site já terá HTTPS automaticamente
- A câmera funcionará normalmente! 📷

---

## 📝 Atualizar o Site

Sempre que fizer alterações:

```powershell
git add .
git commit -m "Descrição das mudanças"
git push
```

O GitHub Pages atualiza automaticamente em alguns minutos.

---

## 🎯 Pronto!

Seu site está online e a câmera funcionará perfeitamente! 🎉
